What the public check requests

It reads the HTTPS homepage, /robots.txt and /.well-known/security.txt, looks up SPF and DMARC in public DNS and opens a TLS connection to read the certificate.

It does not guess paths, test vulnerability fingerprints, submit forms or attempt a login. Redirects are not followed; response sizes and request times are limited. If something cannot be read, the result says so.

For details or to block these requests, see About our checks.
