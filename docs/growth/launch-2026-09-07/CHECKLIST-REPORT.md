# Prima di inviare il report al cliente

Una checklist di comunicazione per agenzie e freelance. Non è una certificazione né una lista esaustiva di controlli di sicurezza.

**Cliente:** ____________________  **Dominio:** ____________________

**Data del controllo:** __________  **Responsabile del seguito:** __________

- [ ] Il destinatario può identificare subito sito, data e perimetro del controllo.
- [ ] Ogni problema riporta ciò che è stato effettivamente osservato.
- [ ] Ho separato le evidenze dalle interpretazioni ancora da verificare.
- [ ] Le priorità sono motivate, senza allarmi sproporzionati.
- [ ] Per ogni intervento ho indicato un prossimo passo e il team a cui proporlo.
- [ ] Ho distinto le decisioni dipendenti dal contesto dai problemi con una correzione concreta.
- [ ] Le osservazioni informative non vengono presentate come controlli di sicurezza superati.
- [ ] Ho indicato come verificare gli interventi, senza segnare come risolto ciò che non è stato ricontrollato.
- [ ] Non compaiono credenziali, token o dati personali non necessari.
- [ ] Ho spiegato che il risultato riguarda la data del controllo e non garantisce assenza di vulnerabilità.
- [ ] Il report resta leggibile su telefono e nel PDF.
